# AI智能招聘管理系统 - 完整项目交付文档

## 项目概述

AI智能招聘管理系统是一个前后端分离的招聘平台，支持HR发布岗位、管理简历，求职者浏览岗位、投递简历，以及AI智能简历分析等功能。

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | Vue 3 + Vite + Element Plus + Pinia |
| 后端 | .NET 8 Web API + EF Core |
| 数据库 | SQL Server / SQL Express / LocalDB |
| 缓存 | Redis |
| 消息队列 | RabbitMQ (可选) |

## 项目结构

```
AIRecruitment/
├── 前端 (Vue 3)

│   │   │   ├── public/   # 求职者端

```

## 快速启动

### 1. 环境要求
- .NET 8 SDK
- Node.js 18+
- SQL Server / SQL Express / LocalDB
- Redis (可选)

### 2. 数据库配置
1. 打开 SSMS 或 SQL Server Management Studio
2. 连接数据库服务器（如 `(localdb)\MSSQLLocalDB`）
3. 执行 `数据库脚本.sql` 创建数据库和表

### 3. 后端启动
```bash
cd Backend/AIRecruitment.Api
dotnet run --urls "http://localhost:5000"
```

### 4. 前端启动
```bash
npm install
npm run dev
```

### 5. 访问系统
- 前端: http://localhost:3000
- 后端API: http://localhost:5000
- API文档: http://localhost:5000/swagger

## 修复记录

### 1. EF Core 外键级联冲突修复
**问题**: `Delivery` 表多个外键同时级联删除导致 SQL Server 报错
**解决**: 在 `AppDbContext.cs` 中将所有外键删除行为改为 `Restrict`

### 2. Swagger 404 修复
**问题**: Swagger 只在 Development 环境下启用
**解决**: 修改 `Program.cs`，让 Swagger 始终启用

### 3. UserService 空引用修复
**问题**: 构造函数中 `_configuration` 未正确赋值
**解决**: 修复构造函数赋值语句

### 4. JobDetail.vue 标签错误修复
**问题**: `<p>` 标签错用 `</h3>` 结束
**解决**: 修改为正确的 `</p>` 结束标签

## 核心功能

### 求职者端
- 浏览岗位列表
- 查看岗位详情
- 投递简历
- 查看投递状态

### HR管理后台
- 岗位发布与管理
- 简历筛选与管理
- AI智能分析
- 面试安排
- 数据统计看板

### AI功能
- 简历智能解析
- 人岗匹配评分
- 面试题自动生成
- 招聘数据分析

## 注意事项

1. **数据库连接字符串**: 根据实际环境修改 `appsettings.json` 中的连接字符串
2. **JWT密钥**: 生产环境请更换强密钥
3. **Redis**: 如不使用可注释相关配置
4. **文件上传**: 生产环境建议配置对象存储（如MinIO、阿里云OSS）
